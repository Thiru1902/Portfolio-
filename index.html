Future-Fund-FuFu

Q-Maintain

Quantum-Enhanced Predictive Maintenance System

A predictive maintenance project developed for the Quantathon, combining classical machine learning and quantum machine learning approaches. The project explores predictive maintenance using XGBoost, QSVM with Qiskit, and a quantum-enhanced XGBoost approach, with comparisons between classical and quantum-based methods. The system also includes live smartphone sensor analysis using Phyphox.

Key Features

  • Predictive maintenance & RUL estimation
  • XGBoost classification & QSVM using Qiskit
  • Quantum-enhanced XGBoost experimentation
  • Live Phyphox sensor analysis
  • Streamlit dashboard
